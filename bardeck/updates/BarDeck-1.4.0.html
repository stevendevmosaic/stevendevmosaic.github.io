New

  • Live data buttons show anything that changes: a button runs a command or fetches a web address every so often and draws the result, with an optional chart. Use Test in the edit window to see exactly what it prints. A button only runs after you approve it, and importing a layout clears every approval.
  • Example scripts for the weather, whether a website is up, what is on TV and smart-meter electricity are on the recipes page of the BarDeck website.
