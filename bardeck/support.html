Support

BarDeck for Mac

Key-press and paste buttons do nothing.
These need the Accessibility permission. Open System Settings → Privacy & Security → Accessibility, and turn BarDeck on. If it is already on and still does nothing, switch it off and on again, then restart BarDeck.
The New Folder button does nothing.
It asks Finder to create the folder, so macOS needs to allow that. Open System Settings → Privacy & Security → Automation and allow BarDeck to control Finder. The folder is made in the front Finder window, or on the Desktop if no window is open.
I can’t see the bar.
It may be hidden. Click the BarDeck icon in the menu bar and choose Show bar, or press the show/hide hotkey (Control-Option-B). If you turned auto-hide on, rest the pointer where the bar was.
How do I move the bar?
Drag the dotted handle at its left end. The bar remembers where you leave it.
How do I add, edit or remove a button?
Right-click the bar. You can add a button or a stack, edit or remove any button, lock buttons so they cannot be moved, and undo recent changes. You can also drag an app, folder, file or web link onto the bar.
I removed something by mistake.
Right-click and choose Undo last change. Older layouts are in Backups → Restore; BarDeck saves one automatically whenever you make changes.
Can I edit my buttons in a text file?
Yes. Choose Edit config file from the right-click menu. Changes are picked up as soon as you save, and a file with a mistake in it is ignored rather than overwritten.
My trial has ended.
The bar shows Trial ended — Buy BarDeck and Enter licence key. Your buttons are kept. After you buy, paste the key into Enter licence key and everything returns.
My licence key isn’t accepted.
Copy the whole key from the email, including the BARDECK- at the start. It is long, so make sure none of it is cut off. If it still fails, email me and say which key you were sent.
macOS says the app can’t be opened.
Drag BarDeck from the downloaded disk image into your Applications folder first, then open it from there.
